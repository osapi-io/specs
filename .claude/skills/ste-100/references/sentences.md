# Sentences

## Length

A procedure sentence has no more than 20 words. A descriptive sentence has no
more than 25. A command or a code identifier counts as one word.

## One topic

| Not STE | STE |
| --- | --- |
| The controller checks the token, and the job goes on the queue where an agent takes it. | The controller checks the token. Then it puts the job on the queue. An agent receives the job from the queue. |

## Verb forms

Use only the imperative, the simple present, the simple past, the simple
future, and the past participle as an adjective.

| Not STE | STE |
| --- | --- |
| The agent will have been restarted by then. | The agent restarts before that. |

## No -ing forms

Do not use an -ing form as a verb or as a noun. Use a clause.

| Not STE | STE |
| --- | --- |
| When running twice, the write reports no change. | When you run the write again, it reports `changed: false`. |

## Voice

Use the active voice in procedures, always. In descriptions, use it where you
can name who or what does the action.

| Not STE | STE |
| --- | --- |
| The token must be generated first. | Make the token first. |
| Every request is recorded. | The audit log records every request. |

## Keep the small words

Do not leave out "the", "a" or "that" to make a sentence shorter.

| Not STE | STE |
| --- | --- |
| Run command on host. | Run the command on the host. |

## Lists

Use a vertical list for three or more items or steps.
