# Descriptions

A description says what a thing is or how it works. Read
[sentences.md](sentences.md) too: a descriptive sentence has 25 words or fewer.

## Most important first

Put the main point in the first sentence of the paragraph.

## One topic, six sentences

One topic in each paragraph, and no more than six sentences in it.

## Say what does it

Name the thing that does the action, where you can.

Not STE:

> In order to make it possible for operators to see what the system is doing
> at any point in time, a number of mechanisms have been put in place,
> including the audit log.

STE:

> The audit log records every request. An operator uses it to see who changed
> a host, and when.
